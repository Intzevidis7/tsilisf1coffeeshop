# 🏎️ TsilisF1CoffeeShop

**Full-stack Formula 1 prediction platform**

🌐 **Live Website:** https://tsilisf1coffeeshop.org/

## 📌 About

TsilisF1CoffeeShop is a full-stack web application built around Formula 1 predictions.

Users can create accounts, submit predictions for upcoming races and compete through a leaderboard system.

The platform also includes an administrative system for managing race results and updating leaderboard standings.

## ✨ Features

* 👤 User registration and authentication
* 🏁 Race prediction system
* 📊 Leaderboard
* 🏆 Driver/racer statistics
* 🔧 Admin panel
* 📝 Race result management
* 🗄️ MySQL database
* 🌐 Production deployment
* ☁️ Cloudflare DNS/CDN configuration

## 🛠️ Tech Stack

* PHP
* MySQL
* JavaScript
* HTML5
* CSS
* Cloudflare
* cPanel

## 🏗️ Architecture

The application uses a PHP-based MVC-style structure with separate controllers for authentication, predictions, leaderboard functionality and race-result administration.

```text
User
 ↓
PHP Application
 ↓
Controllers
 ↓
MySQL Database
 ↓
Leaderboard / Predictions
```
